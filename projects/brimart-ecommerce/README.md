# Brimart – E-Commerce Web Project

## Overview

Brimart is an e-commerce marketplace web project designed to provide customers with an easy way to browse products and explore an online shopping experience.

## Features

- Product browsing
- Product categories
- Search interface
- Shopping cart interface
- Customer account/sign-in interface
- Deals and featured products sections
- Multiple product categories
- Delivery information
- Payment options including M-Pesa, Visa and Mastercard
- Customer service section
